Data Cleaner

Excel data cleaning tool

Upload a messy Excel sheet and run the usual cleaning steps in one go: blank rows, duplicates, nulls, extra spaces, text case, split columns, find and replace. Every change goes into a log that you can undo. It understands Indian formats and works offline in the browser.

A small version runs at the top of this page

How it works
  1. Upload an Excel or CSV file.
  2. Pick the cleaning steps to run together.
  3. Check the change log and undo anything you don't want.
  4. Filter, sort and download the clean file.

Built with

  • JavaScript
  • Excel functions
  • HTML and CSS

AI Flatmate Compatibility

Matching engine with a compatibility score

Scores how well two people would share a flat, as a percentage, from budget, location, sleep schedule and cleanliness. Matched pairs go through automatic ID verification and get a rental agreement template.

How it works
  1. Preferences come in through an intake form.
  2. A Python scoring engine with Gemini calculates the compatibility percentage.
  3. When there is a match, n8n runs automatic ID verification with OCR.
  4. An intro meetup is scheduled and a rental agreement template is sent.

Built with

  • Python
  • Google Gemini
  • n8n
  • SQLite / Airtable
  • OCR / ID API

Smart Parking

WhatsApp booking bot with live availability

Drivers ask for parking on WhatsApp in plain Hindi or English. Gemini reads the request, PostgreSQL checks which spots are free, Razorpay takes the payment, and owner payouts and the platform commission are logged.

How it works
  1. n8n captures the driver's location and Gemini understands the request.
  2. Live spot availability is checked in the database.
  3. The booking is confirmed and a UPI/Razorpay link is sent.
  4. Owner payout and platform commission are logged.

Built with

  • Google Gemini
  • PostgreSQL / Sheets
  • n8n
  • WhatsApp Business API
  • Razorpay

Hyperlocal Ad-Space

QR scan tracking and payout calculation

Local brands put trackable QR ads on tea cups, bottles and bags handed out by street vendors. Every scan is tracked live, and each vendor's monthly payout is calculated from the scan data.

How it works
  1. A brand submits a campaign through a portal.
  2. Trackable dynamic QR codes are generated for cups, bottles and bags.
  3. Print and delivery orders go to nearby vendors automatically.
  4. Scans are tracked live and monthly vendor payouts are calculated.

Built with

  • n8n
  • Google Gemini
  • Dynamic QR API
  • Google Sheets
